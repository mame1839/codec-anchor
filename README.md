# Codec Anchor

イヤホンごとに Bluetooth のコーデックと音質を保存し、そのイヤホンが接続されたときに適用する Xposed
モジュールです。

**常駐しません。** 設定を適用するコードは Bluetooth プロセスの中で動くので、機器の接続を見張るための
常駐プロセスやポーリングが要りません。

[English](README.en.md)

## できること

- イヤホンごとにコーデック、サンプルレート、ビット深度、ビットレートを保存します
- 保存した設定は、そのイヤホンが接続されたときに適用します

## 実行環境

- Android 12 以降
- Bluetooth プロセスに注入できる Xposed フレームワーク。root が必要です
  ([Vector](https://github.com/JingMatrix/Vector) など。LSPatch のような root なしのものでは動きません)

## 使い方

1. [Releases](https://github.com/mame1839/codec-anchor/releases) から APK を入手してインストールします
2. Xposed フレームワークの管理画面で Codec Anchor を有効にし、スコープに Bluetooth を追加します
3. Bluetooth を入れ直すか、端末を再起動します
4. アプリを開き、ペアリング済みのイヤホンを選んで設定します

設定は保存した時点で反映されます。接続中のイヤホンにはその場で適用します。

## 仕様

### 適用のタイミング

接続を検知すると、設定した待ち時間のあとに適用します。再生に使う機器が切り替わったときも同じように
動きます。適用後は値を読み直して確認し、設定と違っていればやり直します。待ち時間、やり直す回数、その
間隔はイヤホンごとに設定します。

### 設定する項目

コーデック、サンプルレート、ビット深度、ビットレートの 4 つです。項目ごとに指定するかどうかを選べて、
指定しなかった項目は端末が決めた値をそのまま使います。コーデックだけ指定して残りは端末に任せることも
できます。選択肢は端末とイヤホンが対応している範囲から作ります。接続していないときは候補をすべて
表示します。

### 他アプリによる変更

システムや他のアプリがコーデックを変更したとき、保存した設定に戻します。この動作はオフにできます。

### 強制適用

イヤホンが対応を申告していない組み合わせも試します。通常の呼び出しで拒否される場合は、最後のやり直しで
Bluetooth スタックに直接指定します。

### HD オーディオ

SBC 以外のコーデックは、機器の HD オーディオ設定が無効だと選ばれません。無効だった場合は有効にしてから
適用します。

### SBC を経由する切り替え

切り替えを受け付けない機器向けの設定です。いったん SBC にしてから、目的のコーデックに変更します。

### 通知

コーデックが変わったときに短いメッセージを表示します。接続直後の一時的な状態では表示せず、確定した結果
だけを表示します。切り替えられなかった場合は、そのときの値を添えて表示します。

### 実効ビットレート

LDAC で接続しているときは、実際に送っているビットレートと品質モードをイヤホンの詳細画面に表示します。
アダプティブビットレートを選んだときに、いまどれくらいで送っているかを見られます。端末が Bluetooth の
音声処理をハードウェアに任せている場合は取得できないので、そのことを表示します。

### 常駐しない

設定を適用するコードは Bluetooth プロセスの中で動くので、機器の接続を見張るための常駐プロセスや
ポーリングが要りません。アプリのプロセスが動くのは、設定画面を開いているとき、フックから設定を要求された
とき、端末を起動したときだけです。ウェイクロックもアラームも使いません。

### バックアップ

設定を JSON ファイルに書き出し、読み込めます。

### 表示言語

英語、日本語、简体中文、繁體中文、한국어、Español、Deutsch、Français、Italiano、
Português (Brasil)、Русский、Polski、Türkçe、Tiếng Việt、Bahasa Indonesia、ไทย、العربية、हिन्दी
の 18 言語です。端末の言語設定に従い、対応していない言語では英語になります。

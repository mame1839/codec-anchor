# Codec Anchor

イヤホンごとに Bluetooth のコーデックと音質を決めておくと、そのイヤホンにつないだときだけ自動で適用される
Xposed モジュールです。

[English](README.en.md)

## できること

- イヤホンごとにコーデック、サンプルレート、ビット深度、ビットレートを保存できます
- 保存した設定は、そのイヤホンが接続されたときに自動で適用されます

## 実行環境

- Android 12 以降
- Xposed フレームワーク ([Vector](https://github.com/JingMatrix/Vector) など)

## 使い方

1. [Releases](https://github.com/mame1839/codec-anchor/releases) から APK を入手してインストールします
2. Xposed フレームワークの管理画面で Codec Anchor を有効にし、スコープに Bluetooth を追加します
3. Bluetooth を入れ直すか、端末を再起動します
4. アプリを開き、ペアリング済みのイヤホンを選んで設定します

設定は保存した時点で反映されます。接続中のイヤホンにはその場で適用されます。

## 仕様

### 適用のタイミング

接続、再生に使う機器の切り替え、コーデックの変化を検知して適用します。適用したあとに実際の値を読み直して
確認し、設定どおりになっていなければ時間を置いてやり直します。適用までの待ち時間、やり直す回数、その間隔は
イヤホンごとに変えられます。

### 項目ごとの「変更しない」

コーデック、サンプルレート、ビット深度、ビットレートはそれぞれ独立して「変更しない」を選べます。
コーデックだけ決めて残りは端末任せにする、といった指定ができます。

### 他アプリによる変更の上書き

システムや他のアプリがコーデックを変更した場合、保存した設定へ戻します。オフにすると、変更されたままに
なります。

### 強制適用

イヤホンが対応を申告していない組み合わせも試します。通常の経路で受け付けられないときは、最後のやり直しで
Bluetooth スタックへ直接指定します。

### HD オーディオの自動有効化

SBC 以外のコーデックは、その機器の HD オーディオ設定が無効になっていると選ばれません。必要なときは自動で
有効にします。

### SBC を経由した切り替え

コーデックの切り替えを受け付けにくい機器向けに、いったん SBC へ落としてから目的のコーデックへ移ります。

### 選べる値

コーデックとその組み合わせは、端末とイヤホンが対応している範囲を読み取って一覧にします。接続していない
間は、すべての候補から選べます。

### 通知

コーデックが切り替わったときに短いメッセージを表示します。接続直後の一時的な状態では出さず、落ち着いた
結果だけを知らせます。切り替えられなかった場合は、そのときの状態を添えて知らせます。

### バックアップ

設定を JSON ファイルに書き出し、読み込み直せます。

### 表示言語

英語、日本語、简体中文、한국어、Español に対応しています。端末の言語設定に従います。

## ビルド

```
./gradlew assembleDebug
```
